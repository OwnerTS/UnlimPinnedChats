# UnlimPinnedChats

Плагин для **exteraGram** (на базе ElyxCore SDK), снимающий ограничения Telegram на количество закреплений чатов:

- Снимает лимит в 5 (или 10 для Premium) закреплённых чатов во вкладке «Все чаты» и папках.
- Позволяет закреплять неограниченное количество чатов локально.
- **Защита облачных закрепов**: локальные закрепы сверх лимита больше не выталкивают и не стирают старые закрепы в облаке Telegram на других устройствах (ПК, веб и т.д.).
- **Настройки (ровно 2 поля)**:
  - **Лимит синхронизированных** (по умолчанию `0` — облако вообще не трогается, либо `1-10` для синхронизации первых N закрепов).
  - **Лимит локальных** (по умолчанию `1000` — максимальное количество локальных закрепов).
- **Кастомный инлайн-ввод**: числовые пилюли прямо в строке настроек с защитой текста от спотыкания об рамки и переносов (`singleLine`, `ellipsize=END`, выверенные отступы).
- Закрепления сохраняются в локальной базе данных SQLite и настройках плагина, поэтому не слетают при перезапуске клиента, обновлении диалогов или очистке кэша.
- Чистая Python-реализация без необходимости нативного DEX-кода.

## Сборка

Для сборки плагина используется [Mandochka](https://pypi.org/project/mandochka):

```bash
# Проверка совместимости с SDK
mandochka check

# Сборка скомпилированного .eaf архива
mandochka build -c 2 -b
```
